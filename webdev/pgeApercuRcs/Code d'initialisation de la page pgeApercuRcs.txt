// ** Déclarations globales de pgeApercuRcs (Serveur)
//
// Page dynamique « écran du téléphone » de l'aperçu RCS, chargée dans
// l'iFrame ifrEcran de popupApercuRcs. Elle ne contient AUCUN champ :
// tout le rendu (HTML + CSS + JavaScript) est renvoyé par ChaîneAffiche,
// qui court-circuite le rendu WebDev de la page.
//
// Les données arrivent par deux globales de projet, écrites par la popup :
//	gsApercuRcsJson : le JSON d'aperçu (Partage.ConstruitJsonApercuRcs)
//	gsApercuRcsMode : android | iphone | sms
//
// Page dynamique (et non AWP) : elle vit dans la session WebDev, donc
// inaccessible sans être connecté — aucun jeton d'accès à gérer.
// L'URL contient un paramètre r= (horodatage) uniquement pour forcer
// le rechargement de l'iFrame ; il n'est pas lu.

// ** Fin d'initialisation de pgeApercuRcs (Serveur)

sHtmlEcran est une chaîne

si gsApercuRcsJson = "" alors
	ChaîneAffiche(ChaîneVersUTF8("<!DOCTYPE html><html><body>Aperçu indisponible.</body></html>"), typeMimeHTML)
	retour
fin

sHtmlEcran = ConstruitHtmlApercu(gsApercuRcsJson, gsApercuRcsMode)

ChaîneAffiche(ChaîneVersUTF8(sHtmlEcran), typeMimeHTML)
