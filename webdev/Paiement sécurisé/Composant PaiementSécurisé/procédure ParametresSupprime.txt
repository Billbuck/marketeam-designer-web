// Résumé : supprime les paramètres et informations reçus de la banque pour un paiement
// Syntaxe :
//[ <Résultat> = ] ParametresSupprime (<sNuméroCommandeOuIdTransaction>, <bDepuisNumeroCommande> est booléen, <bSupprimeEnregistrement> est booléen)
//
// Paramètres :
//	sNuméroCommandeOuIdTransaction : Numéro de commande ou identifiant de transaction
//	bDepuisNumeroCommande (booléen) : Vrai si sNuméroCommandeOuIdTransaction est le n° de commande, Faux si c'est l'identifiant de transaction
//	bSupprimeEnregistrement (booléen) : Vrai pour supprimer totalement l'enregistrement correspondant à ce paiement dans la base des transactions, Faux pour mettre à vide les rubriques avec des informations de retour de la banque
// Valeur de retour :
// 	booléen : Vrai si l'effacement a pu être fait ou s'il n'existe pas
//

bRetour est un booléen

	HLitRecherchePremier(clt_transaction, NumeroCommande, sNuméroCommandeOuIdTransaction)
sinon

	si bSupprimeEnregistrement alors			
		si pas HSupprime(clt_transaction) alors
			XERREUR(HErreurInfo())
			<compile si pas TypeConfiguration=Android>

			<fin>

		sinon

		fin
