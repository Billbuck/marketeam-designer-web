	//   - le filtrage de champsFusion (doctrine fidélité au modèle)

	// L17/A27 — INVERSION DE PRIORITÉ. La valeur du wrapper (= fiche

	//   Quand un utilisateur B (ATTALI Michel) exploite le modèle dans
	//   le tunnel sans base, le wrapper a {Nom:"ATTALI", Prenom:"Michel"}
	//   (fiche utilisateur fraîche). L'ancien bloc écrasait par les
	//   placeholders figés -> pavé adresse du BAT affichait "Monsieur

	//
	//   Nouvelle doctrine V2.5 :
	//     - Clé du modèle déjà présente dans wrapper -> NE PAS écraser
